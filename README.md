# Factory API

## Описание

**Factory API** — REST API для получения информации обо всесх установках на производстве

### Технологии
- **Язык:** Python  
- **Фреймворк:** FastAPI  
- **Библиотеки:** Pydentic, SQLAlchemy
- **База данных:** PostgreSQL

---

## Запуск проекта

**Порт:** `8000`  
**URL:** `http://localhost:8000`

## Docker
**Для запуска, в корневой папке прописать:**
```bash
docker-compose up --build
```
**Для остановки, там же прописать:**
```bash
docker-compose down -v
```
